Weather App 🌤️

Aplicación del clima moderna y responsive que muestra condiciones actuales y pronóstico de 3 días, con fondos dinámicos que cambian según el clima.

---

***REMOVED******REMOVED*** ✨ Características principales 

🌍 Busca el clima por ciudad o usando tu ubicación geográfica

🌡️ Muestra temperatura actual (con opción °C/°F)

📊 Información detallada: humedad, velocidad del viento

📅 Pronóstico de 3 días

🌈 Fondos dinámicos que cambian según las condiciones climáticas

🌙 Modo día/noche automático

📱 Diseño completamente responsive

---

***REMOVED******REMOVED*** 🛠️ Tecnologías utilizadas 

- HTML5

- CSS3 (con animaciones y efectos visuales)

- JavaScript (ES6)

- OpenWeatherMap API

- Font Awesome para íconos
